# 暖心血压通 - 独居老人智能血压监测系统

面向独居高血压老人的轻量级网页血压监测Demo，纯前端实现，打开浏览器即可使用。

---

## 项目简介

针对独居老人日常测量血压时"记录难、判断难、家属远程知晓难"三大痛点，设计的适老化网页工具。系统根据老人年龄、测量时段自动调整血压判断阈值，将数据保存为直观表格和趋势折线图，并同时输出给老人的温和建议和给家属的风险提示。

---

## 核心功能

| 功能模块 | 说明 |
|---|---|
| 智能血压判断 | 根据年龄分档（65岁/80岁）+ 清晨血压晨峰修正，动态判断血压等级 |
| 历史数据表格 | 所有测量记录本地持久化存储，刷新页面不丢失 |
| 血压趋势折线图 | ECharts双折线展示高压/低压变化，带正常范围绿色色带 |
| 双视角个性化建议 | 给老人的口语化提醒 + 给家属的风险提示 |
| 老人/家属模式切换 | 老人模式极简大按钮，家属模式额外展示统计概览 |
| 适老化设计 | 18px+大字号、60px大按钮、暖棕色系高对比度配色 |

## 技术栈

| 类别 | 技术 | 用途 |
|---|---|---|
| 页面结构 | HTML5 | 单页面应用，无路由 |
| 样式 | CSS3 + Flex/Grid布局 | 响应式适配手机/平板/桌面 |

## 使用方法

> ⚠️ 注意：下面提到的 `localhost` 地址都是**你自己电脑上的本地地址**，不是公网网址，必须在你自己电脑上启动服务后才能访问，别人打不开是正常的。

### 方式一：直接打开（最简单，推荐）

1. 下载 `blood-pressure-demo.html` 到本地
2. 双击文件，系统默认浏览器会自动打开
3. 即可开始使用全部功能

> 这种方式下图表依赖ECharts CDN联网加载，需要保持网络正常。

### 方式二：VSCode + Live Server（开发调试推荐）

1. 用VSCode打开项目所在的**文件夹**（不要只打开单个文件）
2. 安装 `Live Server` 插件
3. 右键 `blood-pressure-demo.html` → `Open with Live Server`
4. 浏览器会自动打开 `http://127.0.0.1:5500/blood-pressure-demo.html`

### 方式三：命令行启动临时服务

```bash
# Python 3 环境下，在文件所在目录执行
python -m http.server 8080

# 然后在浏览器访问
# http://127.0.0.1:8080/blood-pressure-demo.html
```

## 常见问题

**Q：折线图加载不出来，显示空白？**
A：ECharts通过CDN加载，需要联网。如果网络受限，可以手动下载 `echarts.min.js` 放到同目录，然后把HTML里的CDN那行改成：
```html
<script src="./echarts.min.js"></script>
```

**Q：数据会丢失吗？**
A：数据存在浏览器LocalStorage里，只要不清除浏览器缓存、不用无痕模式关闭，下次打开还在。换浏览器或换电脑需要重新录入。

**Q：手机上能用吗？**
A：可以。把HTML文件发到手机上，用手机浏览器打开即可，页面已做响应式适配。

## 快速上手操作

1. **填写基本信息**：输入老人姓名和年龄（年龄用于智能判断阈值）
2. **录入血压**：测量血压计上的高压（收缩压）和低压（舒张压），点击「记录本次血压」
3. **查看结果**：页面自动显示血压等级（绿/黄/红三色）和双视角建议
4. **查看趋势**：向下滚动可看到血压变化折线图和历史记录表格
5. **切换家属模式**：点击顶部「家属模式」，可查看总测量次数、正常/异常次数统计
